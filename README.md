# Health economics

Small, self-contained projects on drug pricing and health-care payment, built on public data.

| Project | What it does | Data |
|---|---|---|
| [drug-price-explorer](drug-price-explorer/) | Interactive explorer: pick a drug and see what Medicare pays, what the list price is, and how the 2026 (and 2027) negotiated prices change it. | CMS Medicare Part D and Part B Spending by Drug; CMS Drug Price Negotiation Program fact sheets |

Each project folder has its own README with setup and data-refresh instructions.
